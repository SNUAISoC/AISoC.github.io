# Image GUI patch

Upload/replace these files at repository root:
- `.pages.yml`
- `_data/home.yml`
- `_data/publications.yml`
- `index.html`
- `publications.html`

This makes Home hero and Publications featured images editable in Pages CMS. Existing logo and professor photo were already editable. CSS does not need to be replaced; inline background-image from YAML overrides the old CSS fallback.
